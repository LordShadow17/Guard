# Orbit Bot

A free, original Discord community bot for leveling, role rewards, leaderboards, and moderation, with a private web dashboard for server admins.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server and Discord bot gateway
- `pnpm --filter @workspace/orbit-bot-dashboard run dev` — run the Orbit Bot dashboard
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL`, `SESSION_SECRET`, `DISCORD_BOT_TOKEN`

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `artifacts/api-server/src/lib/discord-bot.ts` — Discord gateway, slash commands, leveling, role rewards, and moderation logging
- `artifacts/api-server/src/routes/orbit.ts` — dashboard API and guild-scoped authorization
- `artifacts/orbit-bot-dashboard/src/pages/orbit-dashboard.tsx` — dashboard and one-time-code sign-in
- `lib/db/src/schema/orbit.ts` — persisted settings, member XP, daily metrics, activity, and rewards
- `lib/api-spec/openapi.yaml` — source contract for the generated client and server validation

## Architecture decisions

- Orbit Bot is an independent alternative, not a copy of Arcane's branding, assets, or private implementation.
- Dashboard access is paired by an administrator-only `/dashboard-code`; codes expire after five minutes, and signed HttpOnly sessions last seven days.
- Message leveling uses sender metadata only; the bot does not request Discord's privileged Message Content intent.
- Reaction XP has its own per-member cooldown and is awarded only for reactions to another member's message.
- Voice XP is awarded per full minute only while at least two non-bot members share a non-AFK voice channel; self-deafened and server-deafened members do not earn it.
- Level thresholds follow a square XP curve: level N begins at N² × 100 XP.
- The first release keeps features free and has no premium gating or billing.

## Product

Servers can earn configurable XP from messages, reactions, and shared voice sessions; announce level-ups with tags; choose rank-card backgrounds; assign level rewards; view leaderboards and activity; and use slash commands for warnings, timeouts, kicks, bans, and bulk message clearing. Admins configure these features in the dashboard.

## User preferences

All bot features in this project should remain free to use.

## Gotchas

- Invite the bot with the `bot` and `applications.commands` scopes. Grant only the server permissions required by commands you enable; Manage Roles is needed for level rewards.
- Server admins sign in with a one-time code generated by `/dashboard-code` in Discord.
- Run the database schema push after changing the Drizzle schema.
